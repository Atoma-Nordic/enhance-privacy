# Enhance+ Privacy Policy

Privacy policy for the [Enhance+ Chrome extension](https://chromewebstore.google.com/) by [Skala Studios](https://skalastudios.no) (Atoma Nordic AS).

**Live URL:** https://atoma-nordic.github.io/enhance-privacy/

## Editing

`index.html` is auto-synced from two source repositories. **Do not edit it directly here** — your changes will be overwritten by the next sync.

Edit one of these files instead, push to `main`, and a workflow will copy the change to `index.html`:

- [`atoma-nordic/skala-site` → `public/privacy.html`](https://github.com/atoma-nordic/skala-site/blob/main/public/privacy.html)
- [`atoma-nordic/enhance-for-infrakit` → `Enhance+/privacy.html`](https://github.com/atoma-nordic/enhance-for-infrakit/blob/main/Enhance+/privacy.html)

GitHub Pages rebuilds automatically once `index.html` is updated.

### One-time setup

For the sync workflows to push here, both source repos need a `PRIVACY_SYNC_TOKEN` secret containing a fine-grained PAT with `Contents: Read and write` permission scoped to `atoma-nordic/enhance-privacy`.
