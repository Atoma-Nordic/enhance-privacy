Privacy Policy — Enhance+ for Infrakit

Last updated: 10 May 2026 · Applies to Enhance+ version 0.41.0 and later

This privacy policy describes how the Enhance+ Chrome extension handles user data. Enhance+ is published by Atoma Nordic AS (org. nr. 937 007 922), Sverresgate 11, 7800 Namsos, Norway, under the product brand Skala Studios.

For privacy-related questions, contact support@skalastudios.no.

1. Summary

Enhance+ is a browser extension that augments the Infrakit web application (app.infrakit.com, test.infrakit.com) with additional tools for the construction and infrastructure industry. Enhance+ does not have its own backend that stores customer project data. All project data the extension touches is fetched from and returned to Infrakit's own servers (Kuura API), and user settings are stored locally in your browser.

We do not sell, share, or transfer your data to third parties for advertising or any other purpose outside what is required to deliver the extension's stated functionality.

2. Data Enhance+ handles

2.1 Authentication information

Enhance+ communicates with the Infrakit Kuura API on your behalf. To do so, it uses one of the following:

  • Session mode: The extension piggybacks on your existing logged-in Infrakit browser tab and forwards API requests through that session. No credentials are read or stored.
  • Token mode: You may provide an Infrakit API token. The token is stored locally in your browser using chrome.storage and is sent only to Infrakit's own servers.
  • Skala OAuth mode: For Enhance+ features that require a Skala Studios account, the extension opens an OAuth login flow against app.skalastudios.no. The resulting access token is stored locally in chrome.storage and is used to authenticate requests to Skala Studios services.

Authentication tokens never leave your browser except to be sent to the service that issued them (Infrakit or Skala Studios).

2.2 Project content from Infrakit

When you use Enhance+ features, the extension reads and writes project data through the Infrakit Kuura API. This may include:

  • Project metadata, folder structures, and codes
  • Logpoints (XYZ coordinates with codes)
  • Model files (LandXML, DXF, IFC, KOF, SOSI)
  • Status markings, line numbers, and other property data embedded in LandXML files
  • Uploaded models (via POST /kuura/v1/model/async-upload)

This data is fetched from Infrakit, processed locally in your browser, and the result is sent back to Infrakit. Atoma Nordic AS does not receive, store, or have access to this project data.

2.3 File processing in the browser

Enhance+ converts and manipulates files locally in your browser, including:

  • TIN surface generation from point clouds (Delaunay triangulation → LandXML)
  • LandXML reading, writing, color control, and splitting
  • DXF generation (site plans, sign plans, general CAD output)
  • IFC point extraction (using web-ifc WebAssembly)
  • PDF report generation (jsPDF)
  • XLSX status sheet generation from LandXML

All file processing happens client-side. Files are not transmitted to Atoma Nordic servers.

2.4 User settings

Enhance+ stores the following in your browser via chrome.storage:

  • Language preference (Norwegian Bokmål / English)
  • UI preferences and feature toggles
  • API token (only if you choose token mode)

Settings stay on your device and are not transmitted to Atoma Nordic AS.

2.5 Host access

Enhance+ requests access to the following hosts to perform its functions:

  • app.infrakit.com, test.infrakit.com — the Infrakit web application the extension augments
  • AWS S3 (eu-west-1) — to read/write model files referenced by Infrakit
  • *.skalastudios.no — for Skala Studios OAuth and license verification

The extension does not access or read content from any other websites.

3. Data we do not collect

Enhance+ does not:

  • Collect web browsing activity outside the hosts listed in section 2.5
  • Track which pages you visit
  • Use analytics, telemetry, or third-party tracking SDKs
  • Read or transmit form data unrelated to its stated functionality
  • Collect personally identifiable information beyond what is required for authentication
  • Sell or share data with advertisers, data brokers, or any other third party

4. Third parties

Enhance+ communicates with the following third-party services on your behalf, when required by a feature you actively use:

Service Purpose Data sent
Infrakit (Kuura API) Read/write project data you have access to Project content, your Infrakit auth token
AWS S3 (eu-west-1) Upload/download model files referenced by Infrakit File contents, signed URL parameters
Skala Studios (app.skalastudios.no) License verification, Skala account features Skala OAuth token

These services have their own privacy policies governing data they receive.

5. Data retention and deletion

  • Local data (settings, tokens) remains in your browser until you uninstall Enhance+ or clear browser storage. Uninstalling the extension removes all locally stored data.
  • Project data is held by Infrakit, not by Atoma Nordic AS. Refer to Infrakit's privacy policy for retention details.
  • Skala Studios account data (if you have a Skala account) is governed by the Skala Studios privacy policy at skalastudios.no/privacy.

To remove all local data, uninstall the extension from chrome://extensions.

6. Security

  • All network traffic uses HTTPS.
  • Authentication tokens are stored using the Chrome storage API.
  • The extension follows Chrome Manifest V3 and requests the minimum permissions necessary for its functionality.

7. Limited Use disclosure

Specifically, Enhance+:

  • Uses data only to provide or improve user-facing features described on the Chrome Web Store listing
  • Does not transfer user data to third parties except as necessary to provide or improve those features, comply with applicable laws, or as part of a merger, acquisition, or sale of assets (with prior user notice)
  • Does not use or transfer user data for serving advertisements, including personalized, retargeted, or interest-based advertising
  • Does not allow humans to read user data, except (a) with your explicit consent for specific items (e.g. troubleshooting), (b) for security purposes, (c) to comply with applicable laws, or (d) where data is aggregated and anonymized for internal operations
